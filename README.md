# Roblox風ミニゲーム 500選（3D一人称）

Three.js で作った、ブロック調の一人称3Dミニゲーム集です。ジャンルごとに100種類、計500ゲームあります。インストールは不要で、`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です。Three.js を jsDelivr から読み込みます）。

## ジャンル

| ジャンル | 遊び方 |
| --- | --- |
| ブレインロット | 広場を歩き回る生き物に近づくと回収。回収した分だけ収入が増える |
| タイクーン | 広場のマスに照準を合わせて建物を建て、強化して稼ぐ |
| RPG | 闘技場に押し寄せるモンスターを近接攻撃で倒す。敵の予兆（脈動）に注意 |
| スローライフ | 柵の中の畑に種を植え、実ったら収穫。昼夜と天気が移り変わる |
| アスレチック | 空に浮かぶ足場をジャンプで渡ってゴールを目指す。落ちたら最後のチェックポイントから再開 |

## 操作

- 移動: WASD / 矢印キー。Shift で走る。スペースでジャンプ（アスレチック）
- 視点: マウス（クリックでマウス視点を開始。Esc で解除）。マウスが使えない環境では、ドラッグで見回せます
- 行動: 左クリック、または E キー（攻撃・設置・収穫）
- 数字キー: 建物・作物の選択（タイクーン・スローライフ）
- Esc: 一覧へ戻る（マウス視点の解除後に押す）/ R: やり直し

## 構成

```
index.html              メニューとゲーム画面（Three.js r160 を jsDelivr から読み込む）
js/common.js            共通（乱数、配色）
js/core/world.js        物理・プレイヤー操作・照準（描画に依存しない純粋な JS）
js/core/render.js       描画・影・光・パーティクル・効果音（Three.js）
js/games/kit.js         共通の部品（キャラクター、木・岩・ランプ、遠景の島、草むら、足場）
js/games/*.js           ジャンルごとのルール（create(config) が build / update / status を返す）
js/catalog.js           500ゲームの定義（テーマ・難易度・ルールの variant・配色・seed）
js/main.js              メニュー、ゲーム画面の進行、入力、HUD、勝敗表示
tests/load.js           テスト用に JS を Node の仮想環境へ読み込む
tests/stub-render.js    テスト用の描画スタブ（描画を省いてロジックだけ動かす）
tests/bots.js           ジャンルごとの攻略ボット
tests/smoke.js          全500ゲームを生成し、ランダム入力で動かす
tests/playtest.js       ボットで全500ゲームを攻略する（クリア率・所要時間）
tests/browser-playtest.js  ヘッドレス Chromium で実際のキー・マウス入力を送って確認する
tests/shots.js          各ゲームの画面を撮影する（描画の目視確認用）
```

各ゲームは「テーマ名」「難易度（0〜1）」「ルールの variant（0〜4）」「配色」「seed」の組み合わせで作られています。同じ番号のゲームは毎回同じ条件で始まります。

URL に `#brainrot-001` のように付けると、そのゲームを直接開けます。

## テスト

```
node tests/smoke.js                 # 全500ゲームが例外なく動く・カタログの整合性
node tests/playtest.js              # 攻略ボットで全500ゲームを攻略（ジャンル指定と -v も可）
THREE_LOCAL=path/to/three.min.js node tests/browser-playtest.js   # ブラウザでの実操作
THREE_LOCAL=path/to/three.min.js node tests/shots.js out-dir      # 画面の撮影
```

`THREE_LOCAL` は、CDN の代わりに Three.js（r160 の `build/three.min.js`）のローカルファイルを使うための指定です。省略すると CDN への接続を試みます。ブラウザ系のテストには Playwright が必要です。`CHROME_PATH` で実行ファイルを指定できます。

ボットは実際のプレイヤーと同じ入力（キー・視点・クリック）だけで操作します。足場の到達性は物理計算で全組を検証しています。ボットの結果はバランスの目安であり、人間の攻略難易度とは一致しない場合があります。

## 既知の制限

- 描画はブラウザの WebGL に依存します。低性能な端末では、影や草むらの量を減らす必要があるかもしれません。
- スマートフォンのタッチ操作には未対応です（マウスとキーボード前提）。
- 物理と見た目は実際のブラウザで確かめていますが、人間が遊んだときの難易度や操作感は未検証です。
- アスレチックの 1 ゲーム（athletic-020）は、ボットではクリアできません（足場の到達は確認済み）。
