# Roblox風ミニゲーム 500選

ブラウザで遊べる Roblox 風（ブロック調）のミニゲーム集です。ビルド不要で、`index.html` をブラウザで開くだけで動きます。

## ジャンル（各100種・計500）

| ジャンル | 遊び方 |
| --- | --- |
| ブレインロット | 生き物を集めて収入を増やし、スコア目標を目指す |
| タイクーン | 空きマスに建物を置いて稼ぎ、建物を強化する |
| RPG | 押し寄せるモンスターを倒してレベルアップ（HP0で敗北） |
| スローライフ | 作物を植えて育て、収穫して稼ぐ（失敗なし） |
| アスレチック | 横スクロールの足場をジャンプで渡ってゴールを目指す |

## 操作

- 移動: 矢印キー / WASD
- 攻撃・ジャンプ: スペースキー（RPG は クリックでも攻撃）
- 建物・作物の選択: 数字キー（タイクーン・スローライフ）、または画面下のボタンをクリック
- Esc: 一覧へ戻る / R: やり直し

## 構成

```
index.html          メニューとゲーム画面
js/common.js        共通（乱数、ブロック描画、入力の軸計算）
js/games/*.js       ジャンルごとのルール（create(config) が update / draw / status を返す）
js/catalog.js       500ゲームの定義（テーマ・難易度・variant・配色・seed）
js/engine.js        メニュー、ゲームループ、キー/ポインタ入力
tests/smoke.js      全500ゲームをランダム入力で動かす確認スクリプト
```

各ゲームは `難易度（0〜1）`、`variant（0〜4、ルールの微調整）`、`テーマ名`、`配色`、`seed` の組み合わせで作られています。同じ番号のゲームは毎回同じ条件で始まります。

URL に `#brainrot-001` のように付けると、そのゲームを直接開けます。

## テスト

```
node tests/smoke.js
```

全500ゲームが例外なく動くこと、カタログが各ジャンル100件・タイトルが一意であることを確認します。ゲームのバランス（クリア可能性）はこのテストでは確認していません。
